# 📌 Project Overview
This project focuses on analyzing job postings related to the data field using SQL and PostgreSQL. The main goal is to explore the job market, understand which positions offer higher salaries, identify the most in-demand skills, and discover which technologies can be useful for building a career as a Data Analyst.

This project is part of my learning journey in data analytics and allows me to practice SQL queries using real-world job market data.


# 🎯 Objectives
- Identify the highest-paying Data Analyst positions.

- Analyze the skills required for high-paying jobs.

- Identify the most in-demand skills in job postings.

- Compare average salaries associated with different skills.

- Explore which skills may be worth developing for a career in data analytics.
# 🛠️ Tools Used
- SQL: To query, filter, join, and analyze data.

- PostgreSQL: As the relational database management system.

- Visual Studio Code: To write and execute SQL queries.

- Git and GitHub: To organize, version-control, and share the project.

# 🔎 The analysis
This project uses SQL queries to explore different aspects of the data analytics job market.

### 1. Top-Paying Data Analyst Jobs

Analyze Data Analyst job postings to identify opportunities with the highest average annual salaries.

### 2. Skills Required for High-Paying Jobs

Join job postings with their associated skills to identify the technical skills required for the highest-paying opportunities.

### 3. Most In-Demand Skills

Use aggregation functions to count how often specific skills appear in job postings and identify the most frequently requested skills.

### 4. Average Salary by Skill

Calculate the average annual salary associated with different skills to explore their relationship with compensation.

### 5. Skill Demand and Salary for Remote Positions

Use Common Table Expressions (CTEs), JOIN, GROUP BY, COUNT(), and AVG() to compare skill demand and average salaries for remote Data Analyst positions with reported annual salary information.
